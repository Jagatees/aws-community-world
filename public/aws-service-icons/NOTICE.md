# AWS service icons

These assets identify AWS products and related workshop topics. Amazon Web Services, AWS product names and their icons are trademarks of Amazon.com, Inc. or its affiliates. Their use does not imply AWS endorsement of this community website.

Primary source: [AWS Architecture Icons](https://aws.amazon.com/architecture/icons/), July 31, 2026 release. Additional icons come from the January 30, 2026 package linked by the [Japanese AWS Architecture Icons page](https://aws.amazon.com/jp/architecture/icons/).

Legacy product icons come from pinned releases of [AWS Labs' AWS Icons for PlantUML](https://github.com/awslabs/aws-icons-for-plantuml), which generates icons from the official AWS Architecture Icons. Their Creative Commons Attribution-NoDerivs 2.0 license is included in `LICENSE-AWS-ICONS.txt`.

Kiro's icon comes from [kiro.dev](https://kiro.dev/). The AWS SAM squirrel comes from the [AWS Samples SAM farm](https://github.com/aws-samples/aws-serverless-samfarm), and is identified as SAM branding in the [AWS Compute Blog](https://aws.amazon.com/blogs/compute/serverless-conference-and-more/).

`SOURCES.json` records the original URL, archive entry where applicable, and SHA-256 of every included asset. Files are copied unchanged. Only the icons used by the workshop catalog are included.

Some features use the official parent service icon. App2Container, Dash Cart, and Billing & Cost Management use official category icons where a dedicated icon was not found. The mapping records these distinctions in `src/data/aws-service-icons.json` and shows them in each icon's tooltip. New, unmapped services or failed images receive a text abbreviation, never an unrelated service logo.
