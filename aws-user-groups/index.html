Find AWS User Groups near you

AWS User Groups are community-led groups where people using AWS meet, share what they’re building, and learn from local talks and workshops.

Search the AWS User Groups directory

Find a group by city or country

  1. Search the directory for your city or group name, or filter by country.
  2. Open a group’s profile and follow its public link.
  3. Check the group’s page for upcoming meetups, venue details, and how to RSVP.

You can also browse User Groups on the map to find nearby communities across cities or borders.

Start or join a group

The official AWS User Groups page lists groups and explains how to start one. If you’re looking for activities on campus, browse AWS Student Builder Groups.

Explore events and people

Find AWS community events for meetups, workshops, and Community Days, or discover AWS Community Builders by country.
